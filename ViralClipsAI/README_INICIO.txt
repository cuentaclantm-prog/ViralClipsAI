VIRALCLIPS AI — PAQUETE PARA GENERAR EL INSTALADOR DE WINDOWS 10 64 BITS

IMPORTANTE:
Este paquete contiene el proyecto y la receta automatizada para producir el instalador .EXE.
El archivo instalador final todavía no está compilado aquí: la compilación debe ejecutarse en Windows.
No necesitas instalar Python en tu PC para USAR el instalador final.

OPCIÓN MÁS SENCILLA PARA OBTENER EL INSTALADOR:
1. Crea una cuenta gratuita en GitHub.com (si no tienes una).
2. Crea un repositorio nuevo llamado ViralClipsAI.
3. Sube TODO el contenido de esta carpeta al repositorio, incluyendo la carpeta oculta .github.
4. En GitHub, abre la pestaña Actions.
5. Selecciona "Build Windows installer" y pulsa "Run workflow".
6. Cuando termine correctamente, abre la ejecución y descarga el artefacto:
   ViralClipsAI-Installer-Windows10-x64
7. Dentro encontrarás ViralClipsAI_Setup_Windows10_64bit.exe.
8. Ejecuta el instalador en Windows 10 de 64 bits.

AL ABRIR EL PROGRAMA:
- Se abrirá el panel en tu navegador automáticamente.
- La primera vez, Whisper descargará el modelo de español/voz (puede ocupar varios cientos de MB).
- Los videos y clips se guardan en:
  %LOCALAPPDATA%\ViralClipsAI

REQUISITOS Y LIMITACIONES:
- Conexión a Internet para procesar enlaces y descargar el modelo de IA.
- CPU y memoria suficientes; el procesamiento puede tardar.
- Descargas de TikTok/Instagram pueden fallar por cambios o restricciones de sus plataformas.
- Usa videos propios o con permiso. No se evaden cuentas privadas, DRM ni controles de acceso.
- La selección de momentos es una heurística inicial; no garantiza viralidad.
- Esta compilación no ha sido probada todavía en tu PC Windows 10.

Si no quieres crear GitHub ni subir archivos, necesitarás que alguien con un entorno Windows compile el instalador y te comparta el .EXE.
